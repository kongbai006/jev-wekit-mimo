# Jev 聊天助手 · WeKit 版

本地秒判 + 可选接入任意 OpenAI 兼容大模型给聊天建议和 3 条候选回复，候选自动复制到剪贴板，手动粘贴发送。**绝不自动发消息**，只私聊不群聊。

## 安装

1. 解压到 WeKit 的脚本目录：`/sdcard/Android/data/com.tencent.mm/WeKit/scripts_java/`
2. **注意：脚本目录一个文件夹对应一个脚本**，文件夹叫什么，WeKit 里就显示什么。
   - 正确：`scripts_java/jev/main.java` + `info.prop`
   - 错误：把 main.java 直接丢在 `scripts_java/` 根目录（WeKit 只认文件夹）
3. 在 WeKit 里点「刷新」，启用 Jev聊天助手WeKit版。

## 使用

1. 打开和对方的私聊窗口，输入 `/jev` 回车，点「开启本会话」作用域。
2. 作用域开启 = 第一轮本地判断自动跑（秒出意图/危险/情绪）。
3. 「第二轮决策开关（更聪明版）」= 是否调用大模型，关了就只用本地判断。
4. 开了第二轮后：
   - 「大模型分析前手动确认」：收到消息弹框，里面是「对方说 + 本地判断 + 是否分析」，点分析才调大模型；
   - 「策略模式」：用更完整的策略 prompt，更准但更慢；
   - 「撤回第一轮本地判断」：大模型结果出来后把之前的灰字撤回；
   - 「关闭聊天灰字（结果只走弹窗）」：所有结果都不往聊天里插灰字，改弹窗显示。

## 配置项

| 字段 | 说明 |
|---|---|
| API 密钥 | sk- 开头，填你的 OpenAI 兼容 key |
| API 地址 | `/v1` 结尾，默认 `https://api.xiaomimimo.com/v1` |
| 模型名 | 如 `deepseek-chat`、`qwen-plus`、`gpt-4o-mini`，非推理类更快 |
| 聊天对象类型 | 不指定 / 男女朋友 / 想追的人 / 普通朋友 / 同事 / 客户 |
| 关系补充说明 | 自由文本，如「认识三个月，异地」 |
| 上下文轮数 | 0-30，读最近几条对方消息拼给大模型 |

## v3.2 更新

- **结构调整**：作用域 = 第一轮开关；下面的 ToggleButton 改名「第二轮决策开关（更聪明版）」，关掉就不调大模型；
- **配置界面折叠**：只有打开第二轮开关，下面的 API/模型/关系/策略等选项才显示；
- **合并弹窗**：开手动确认后，一个弹窗里同时显示「对方说 + 本地判断 + 是否分析」，不再弹两个；
- **关闭聊天灰字开关**：开启后所有结果走弹窗，不往聊天里插灰字；
- **修 bug**：上下文轮数=0 时不再发空消息给大模型；
- **修 bug**：确认弹窗不再把历史分析结果混进去（过滤了我们自己插的系统消息）；
- **配色**：聊天对象类型下拉框文字改白色；
- 适配任意 OpenAI 兼容 API，不绑定 MiMo。
